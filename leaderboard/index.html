Protocol

How ranking works

Verified runs

Only maintainer-reviewed run IDs enter the public aggregation. Debug and synthetic records remain in Console.

Task macro average

Each evaluated task contributes equally. Missing task metrics remain unavailable instead of silently becoming zero.

Tie breaking

Official score, task success, coverage, then method name determine a stable ordering.
