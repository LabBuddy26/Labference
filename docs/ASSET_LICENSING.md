# Asset licensing and distribution

The repository's MIT License covers first-party software only. Simulator
assets and derived media have separate records in
`eai4s_eval/configs/assets/asset_licenses_v1.json`.

The public website exposes object metadata only. It does not publish source
assets, derived thumbnails or per-object licence records. The registry remains
in the GitHub source repository for internal review and release validation.

Each record reports provenance status, copyright holder, SPDX identifier,
source and licence links, attribution, modifications, and whether the source
asset or derived media may be redistributed.

`pending` and `NOASSERTION` do not grant permission. Such assets, thumbnails
and videos are removed by the public release builder. A record may be changed
to `verified` only after the responsible maintainer has evidence that the
stated licence applies and permits the intended distribution.

Catalogue presence is metadata only and is not a download or redistribution
grant.
