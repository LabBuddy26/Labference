Outcome-grounded evaluation

From observed evidence to reliable action.

Controlled evidence variations

Keep the task goal and rule fixed while varying the physical evidence that should change the next choice. Measure operation selection, physical execution, task completion and recovery separately.

Matched Oracle-assisted continuations

Resume from shared physical checkpoints with scoped state, decision, geometry or execution support. Compare subsequent choices and completion to identify which support helps.

The report’s initial experiments concern feedback weighing. Fine-tuned VLA policies show target-selection errors despite successful transfers; GPT-driven control selects correctly but still encounters execution failures and substantial computation costs. These findings do not establish results across every task.
