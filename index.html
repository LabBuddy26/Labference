Abstract

LabBench is a chemistry laboratory manipulation dataset and benchmark for embodied agents. It provides 24 long-horizon and reasoning-in-action tasks, an object metadata catalogue, synchronized RGB and robot-state trajectories, and two capability leaderboards measuring both reliable multi-stage procedure execution and visual/structured-state reasoning.

Every task ships an explicit success predicate, so completion and quality are scored from independent simulator state rather than controller phase completion.

How LabBench works

LabBench couples a reproducible collection pipeline with an independent success evaluator, so agents are measured on the same physics, cameras and state clock from data collection to evaluation.

Collection

Front and wrist RGB, seven arm joints and gripper state are recorded at 10 Hz over 60 Hz physics into HDF5 episodes.

Data contract

Observations, actions, phase annotations and timestamps share one sampling clock; per-episode instructions keep task identity aligned.

Evaluation

Completion and task-specific quality are scored from simulator state; only verified runs enter the public leaderboard.
