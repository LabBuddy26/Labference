# Contributing

Thank you for improving LabBench. Please open an issue before a substantial
change and keep each pull request focused.

The internal development repository is the source of truth. Accepted public
changes are applied internally, tested there, and returned through a generated
public sync pull request. Do not add datasets, checkpoints, simulator assets,
rendered media, credentials, private endpoints or machine-specific paths.

Every new asset reference requires a complete licence record and review.
Run the unit tests and public release validator before requesting review.
